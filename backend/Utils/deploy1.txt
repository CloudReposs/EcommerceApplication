MERN STACK DEPLOYMENT ON AZURE VM
WITHOUT PM2 AND WITHOUT REVERSE PROXY
FRONTEND ACCESS USING PUBLIC_IP:3000

====================================================
ARCHITECTURE
============

Browser
↓
Frontend React/Vite Application :3000
↓ API Requests
Backend Node/Express Server :5000
↓
MongoDB Database

====================================================
STEP 1 — CREATE RESOURCE GROUP
==============================

Azure Portal → Search:

Resource Groups

Click:

Create

Configuration:

Resource Group Name:
mern-rg

Region:
Central India

====================================================
STEP 2 — CREATE VIRTUAL MACHINE
===============================

Azure Portal → Search:

Virtual Machines

Click:

Create → Azure Virtual Machine

Configuration:

Resource Group:
mern-rg

VM Name:
vm1

Region:
Central India

Image:
Ubuntu Server 22.04 LTS

Size:
Standard_B1s

Authentication:
SSH Public Key

Username:
azureuser

Allow Inbound Ports:

22
3000
5000

Download:

vm1_key.pem

====================================================
STEP 3 — CONNECT TO VM
======================

chmod 400 vm1_key.pem

ssh -i vm1_key.pem azureuser@PUBLIC_IP

Example:

ssh -i vm1_key.pem azureuser@20.xx.xx.xx

====================================================
STEP 4 — UPDATE UBUNTU
======================

sudo apt update

sudo apt upgrade -y

====================================================
STEP 5 — INSTALL NODEJS
=======================

curl -fsSL https://deb.nodesource.com/setup_20.x | sudo -E bash -

sudo apt install nodejs -y

node -v

npm -v

====================================================
STEP 6 — INSTALL GIT
====================

sudo apt install git -y

git --version

====================================================
STEP 7 — CLONE PROJECT
======================

git clone YOUR_GITHUB_REPO_LINK

Example:

git clone https://github.com/username/blog-application.git

cd blog-application

====================================================
STEP 8 — BACKEND SETUP
======================

cd backend

npm install

nano .env

Example:

PORT=5000

MONGO_URI=YOUR_MONGODB_CONNECTION_STRING

SAVE:

CTRL + O
ENTER
CTRL + X

====================================================
STEP 9 — CONFIGURE BACKEND HOST
===============================

nano server.js

Update:

app.listen(5000, "0.0.0.0", () => {
console.log("Server Running");
});

====================================================
STEP 10 — START BACKEND
=======================

npm start

OR

node server.js

Backend URL:

http://PUBLIC_IP:5000

IMPORTANT:

Keep this terminal open.

====================================================
STEP 11 — OPEN SECOND SSH TERMINAL
==================================

ssh -i vm1_key.pem azureuser@PUBLIC_IP

====================================================
STEP 12 — FRONTEND SETUP
========================

cd ~/blog-application/frontend

npm install

====================================================
STEP 13 — UPDATE FRONTEND API URL
=================================

Replace:

localhost:5000

with:

http://PUBLIC_IP:5000

Example:

axios.get("http://20.xx.xx.xx:5000/api/posts")

====================================================
STEP 14 — START FRONTEND
========================

For Vite:

npm run dev -- --host 0.0.0.0

For Create React App:

HOST=0.0.0.0 npm start

====================================================
STEP 15 — VERIFY PORT 3000
==========================

sudo ss -tulnp | grep 3000

Expected:

0.0.0.0:3000

====================================================
STEP 16 — AZURE NETWORKING
==========================

Azure Portal → VM → Networking

Allow Inbound Rules:

22
3000
5000

Protocol:
TCP

Action:
Allow

====================================================
STEP 17 — ACCESS APPLICATION
============================

Frontend:

http://PUBLIC_IP:3000

Backend:

http://PUBLIC_IP:5000

Example:

http://20.xx.xx.xx:3000
